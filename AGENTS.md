# ANYpost working instructions

Read the current global `~/.codex/AGENTS.md`, `ECOSYSTEM_GUIDE.md`, and needed
ranges of the canonical ecosystem philosophy before substantial work.

Use `docs/IMPLEMENTATION_TASK.md` as the single living task record. Keep solver
physics in ANYsolver-results, rendering in ANY3dView, and application ownership
in its repository. Preserve existing dirty work and source-scoped evidence.

Treat case status, model/mesh identity, coordinate basis, units and native sample
associations as governing contracts. Do not invent absent fields, interpolate
across incompatible sample layouts, execute archive-supplied code, or silently
weaken numerical tolerances. Native v1 archives have no external backing data.

Verify changes by impact. Required acceptance includes typed refusal, mutation
and cancellation paths, installed artifacts, and actual frame presentation where
claimed. Passed synthetic throughput does not broaden scientific qualification.
Keep full diagnostics outside source and report precise commands, process-wall
durations, source identities, counts and remaining limits. Do not commit, push or
publish unless requested.
